# Webmint Solutions — Website

A responsive, six-page static website with a dark navy/blue visual theme.

## Pages
- `index.html` — Home
- `about.html` — About Webmint Solutions
- `courses.html` — Courses and learning pathways
- `products.html` — Products and services
- `careers.html` — Sample vacancies and internship application form
- `contact.html` — Contact details and enquiry form

## Run in Visual Studio Code
1. Extract `Webmint_Solutions_Website.zip`.
2. Open the extracted `webmint_solutions` folder in VS Code.
3. Install the **Live Server** extension (Ritwick Dey), if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Important before publishing
- The job roles shown are sample vacancy categories, not confirmation of live openings.
- Course and service descriptions are illustrative. Confirm actual offerings before publishing.
- The enquiry and internship forms currently validate in the browser and show a demo confirmation only. They do **not** send, save, or email submissions. Connect a secure backend (for example, a custom API or a form service) before collecting real applications.
- No company email address or social links were supplied, so those have not been invented.
- Google Fonts are loaded from Google Fonts; an internet connection is needed for those fonts. The site itself is static and needs no build step.
- Confirm the address and phone number before going live.

## Customisation
- Update colours and layout in `assets/style.css`.
- Update interactions in `assets/main.js`.
- Replace sample course, product and vacancy content with verified company information.
